This project builds a Decision Tree model to predict whether a person will buy a computer based on features like age, income, student status, and credit rating.

Libraries used: Pandas, NumPy, Matplotlib, Scikit-learn

Project Flow:

Create and explore dataset

Convert categorical data to numerical

Train Decision Tree model

Analyze feature importance

Evaluate model using Accuracy, Precision, Recall, F1 Score, and Confusion Matrix
